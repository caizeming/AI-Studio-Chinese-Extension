# Google AI Studio 浏览器汉化插件

这是一个轻量级的 Edge/Chrome 浏览器扩展，用于将 [Google AI Studio](https://aistudio.google.com/) 的英文界面实时翻译为中文。

## 功能特点
* 全局界面汉化：覆盖侧边栏、Playground、Build 应用库、模型选择面板、运行设置、环境设置等主要界面。
* 实时动态翻译：支持单页应用（SPA）异步加载的内容；Angular 重新渲染把文本改回英文后会自动重新翻译。
* 支持输入框占位符（Placeholder）翻译。为避免与页面 tooltip 系统产生冲突导致卡死，不翻译 `title` / `aria-label` / `data-tooltip` 属性。
* 智能匹配引擎：
  * 精确词典匹配（约 300 条词条，撇号 `'` / `'` 自动归一化）。
  * 前缀规则：处理 `Release date: 9月 2, 2026` 这类动态拼接文本。
  * 正则规则：处理相对时间（`4 months ago` → `4 个月前`）、分页（`1 – 10 of 137`）、价格行等动态文本。
  * token 兜底：翻译句子中的 `Input:` / `Output:` 等片段。
* 防重复/防循环：已翻译（含中文）的文本自动跳过。

## 安装说明
1. 下载本项目代码（或在 Releases 中下载 `.zip` 压缩包并解压）。
2. 打开 Edge/Chrome 浏览器，在地址栏输入 `edge://extensions/`（Chrome 为 `chrome://extensions/`）。
3. 在页面左侧/右上角开启 **"开发人员模式"**。
4. 点击 **"加载解压缩的扩展"** 按钮。
5. 选择项目文件夹即可。
6. 更新代码后，在扩展页面点击 **"重新加载"**，再刷新 AI Studio 页面生效。

## 如何扩充词典？
如果你发现有未翻译的英文，打开 `content.js`，按以下三种方式添加：

1. **固定文案**（最常用）：在 `dictionary` 对象中添加 `"英文": "中文"`。
2. **动态拼接文本**（英文 + 动态后缀，如日期）：在 `prefixRules` 数组中添加 `["英文前缀", "中文前缀"]`。
3. **动态格式文本**（如相对时间、分页）：在 `regexRules` 数组中添加正则与替换函数。

> 提示：添加词条时注意撇号类型——引擎会自动把弯撇号 `'` 和直撇号 `'` 归一化，无需两种都写。

保存后在浏览器扩展页面点击"重新加载"即可生效。

## 运行测试
项目内置词典命中率测试（Node.js）：

```bash
node test/dict.test.js
```

测试使用从真实 AI Studio 页面抓取的文本样本验证翻译覆盖率与误翻译情况。
